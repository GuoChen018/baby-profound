# Inline Tooltip — variants

**No variants.** A single visual: black `--fill-primary` pill, white `--text-inverse` text, 12/14 Medium, `radius-4`, `px-8 py-6`, `max-w-[200px]`.

## How it differs from Tooltip

| | Inline Tooltip | Tooltip |
|---|---|---|
| Background | dark `--fill-primary` | light `--bg-primary` |
| Text | white | dark |
| Font | 12/14 Medium | 13/16 Medium + 13/1.7 Regular body |
| Border | none | 1px `--fill-quaternary` |
| Shadow | none | "High" drop shadow |
| Radius | `--radius-4` | `--radius-6` or `--radius-8` |
| Use | terse hover hint (1 line) | rich content (citation, chart, region) |
